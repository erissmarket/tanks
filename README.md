# Tank Battle

بازی دوبعدی نوبتی تانک با هفت سلاح، سه کلاس تانک، سه محیط، زمین تخریب‌پذیر، گاراژ و پیشرفت محلی.

**راهنمای کامل تحویل:** [PROJECT_HANDOFF.fa.md](PROJECT_HANDOFF.fa.md)

این راهنما ساختار پروژه، تمام آبجکت‌های مستقل صحنه، نمونه‌های Prefab و Overrideهای آن‌ها، اسکریپت‌ها، سلاح‌ها، تانک‌ها، سپرها، اقتصاد، ذخیره، مسیرهای اتصال بک‌اند و روش ساخت و آزمون را توضیح می‌دهد.

## اجرای پروژه

۱. پروژه را با **Unity 6000.5.10f1** در Unity Hub باز کنید.
۲. منتظر نصب بسته‌های ثبت‌شده و واردکردن دارایی‌ها بمانید.
۳. صحنهٔ `Assets/_Game/Scenes/MVPIntegrated.unity` را باز کنید و Play را بزنید.
۴. از منوی بازی محیط، سلاح شروع و تجهیزات را انتخاب کنید و مسابقه را شروع کنید.

حرکت با A/D، نشانه‌گیری با W/S، شلیک با Space و انتخاب هفت سلاح با کلیدهای عددی انجام می‌شود. کنترل روی صفحه نیز وجود دارد.

## وضعیت تحویل

- بازی فعلی محلی و حریف آن AI است؛ شبکه، حساب آنلاین و سرویس بک‌اند هنوز پیاده نشده‌اند.
- ۱۰۸ بررسی فازهای اول تا ششم و ۱۷۶ بررسی فاز هفتم موفق بوده‌اند؛ ۱۶۸ بررسی آخر ترکیب‌های مجاز تجهیزات، محیط و سلاح هستند.
- ساخت آزمایشی Windows x64 و هفت بررسی تکمیلی روی نسخهٔ مستقل موفق بوده‌اند.
- ساخت APK و تست گوشی واقعی باقی مانده‌اند؛ روی نصب آزمایش، Android Build Support موجود نبود.
- گزارش‌ها در [Docs/Verification](Docs/Verification) و شرح فازها در [Docs/Design](Docs/Design) قرار دارند.

برای ساخت ویندوز از `Tools > Tank Game > Phase Seven > Build Windows Test Version` استفاده کنید. خروجی در `Builds/Windows` ایجاد می‌شود. فایل اجرایی و پوشه‌های همراه را با هم توزیع کنید. خروجی‌های ساخت و فایل ذخیرهٔ بازیکن در Git قرار نمی‌گیرند.
